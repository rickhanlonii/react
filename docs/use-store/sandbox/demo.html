Sandbox demo

Every sandbox on this page runs real React in an iframe, offline from file://. It exercises each feature of host.js once. API.md documents them.

These sandboxes run : the development build, without the React Compiler, with StrictMode off unless a sandbox turns it on. The stepper sandbox uses the mock scheduler, so it's stepped for illustration.

A store, a log and render counts

Click the button. The render strip counts renders and the outline shows what rendered. Try Edit, change the code, and Run.

Conditional reads and the store panel

Every row reads selected. Only open rows read details, so the store panel shows its readers change as you open and close rows.

Stepping a transition

Add 1 in a transition renders the pending state right away, and the transition waits for "Next commit". The store panel shows the update waiting in the queue.

Suspense with a manual resource

createResource() without a loader waits for resolve. <Slow> blocks for a few milliseconds while it renders. This preview has a fixed height.

Server rendering and hydration

With data-server, the code can import react-dom/server. It renders to a string, puts it in the page and hydrates it. This sandbox is read-only and waits for a click on Run.

A reducer that throws

The reducer throws during render, in every component that reads the store. With no error boundary, the error is uncaught and the overlay shows it.

React's own warnings, in StrictMode

The console panel shows what React prints. This list has no keys, and the sandbox starts with StrictMode on.
